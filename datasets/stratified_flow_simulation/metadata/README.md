# Stratified Flows Attenuation - Simulation Dataset

This dataset supports the PhD study: "Study on the Attenuation Mechanisms in Stratified Flows: 2. Simulation Data (For Model Development and Hypothesis Testing)."

Categories:
- CFD Model Outputs
- Mathematical Model Outputs
- Model Validation Data

All data are synthetic, generated by numerical surrogate models mimicking CFD and mathematical predictions for stratified two-phase (gas–liquid) flows under acoustic excitation. See `metadata/schema.json` for detailed field descriptions.
