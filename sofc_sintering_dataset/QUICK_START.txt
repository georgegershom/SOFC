================================================================================
  快速使用
================================================================================

1. 查看可视化图表:
   打开 figures/ 目录查看所有生成的图表

2. 查看数据文件:
   - raw_data/ - 原始实验数据 (CSV格式)
   - processed_data/ - 处理后的本构模型参数 (JSON格式)

3. 安装Python依赖:
   pip install -r requirements.txt

4. 运行示例程序:
   python3 scripts/load_dataset.py

5. 数据可视化:
   python3 scripts/visualize_dataset.py

6. Norton定律验证:
   python3 scripts/validate_norton_law.py

================================================================================
  Python API 示例
================================================================================

from scripts.load_dataset import SOFCSinteringDataset

# 创建数据集对象
dataset = SOFCSinteringDataset()

# 获取Norton蠕变参数
params = dataset.get_norton_parameters('anode', temperature_C=1000)

# 计算蠕变应变率
strain_rate = dataset.calculate_creep_rate(
    layer='anode',
    temperature_C=1000,
    stress_MPa=2.0,
    relative_density=0.70
)

# 计算杨氏模量
E = dataset.calculate_youngs_modulus(
    layer='electrolyte',
    temperature_C=1200,
    relative_density=0.90
)

================================================================================
  材料覆盖
================================================================================

1. 阳极 (Anode): Ni-YSZ (60wt% NiO - 40wt% 8YSZ)
2. 电解质 (Electrolyte): 8YSZ (8mol% Y₂O₃-stabilized ZrO₂)
3. 阴极 (Cathode): LSM-YSZ (50wt% La₀.₈Sr₀.₂MnO₃ - 50wt% 8YSZ)

数据范围:
- 温度: 25 - 1450°C
- 应力: 0.5 - 5.0 MPa
- 相对密度: 0.53 - 0.99
- 应变率: 10⁻⁶ - 10⁻³ s⁻¹
