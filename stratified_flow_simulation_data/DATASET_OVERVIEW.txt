WHAT'S INCLUDED
================================================================================

1. CFD SIMULATION DATA (10 files, ~220 MB)
   ✓ 3D velocity fields (u, v, w components)
   ✓ 3D pressure field with stratification
   ✓ Volume of Fluid (VOF) phase distribution
   ✓ Turbulence parameters (k-ε model: k, ε, μ_t)
   ✓ Time-resolved acoustic pressure propagation
   ✓ Grid coordinates and metadata

2. MATHEMATICAL MODEL OUTPUTS (9 files, ~0.5 MB)
   ✓ Sound speed predictions (Wood's equation & dispersive model)
   ✓ Attenuation coefficients (50 frequencies × 20 void fractions)
   ✓ Wave propagation patterns (reflection, transmission, standing waves)
   ✓ Time-delay estimates for various configurations
   ✓ Model parameters and settings

3. VALIDATION DATA (6 files, ~0.5 MB)
   ✓ Simulated vs. "experimental" acoustic waveforms
   ✓ Attenuation coefficient comparisons with uncertainties
   ✓ Sound speed comparisons with uncertainties
   ✓ Statistical validation metrics (correlation, RMSE, MAE)

4. VISUALIZATION FIGURES (8 files, ~5 MB)
   ✓ Velocity field plots (4-panel with u, v, w, magnitude)
   ✓ VOF and pressure fields
   ✓ Turbulence parameters (k, ε, μ_t)
   ✓ Acoustic pressure time snapshots (4 times)
   ✓ Sound speed predictions (2 models)
   ✓ Attenuation vs. frequency and void fraction
   ✓ Wave propagation patterns
   ✓ Validation comparisons (4-panel)

5. DOCUMENTATION & TOOLS (5 docs + 3 scripts)
   ✓ README.md - Complete technical documentation
   ✓ QUICKSTART.md - 5-minute getting started guide
   ✓ DATASET_SUMMARY.md - Quick reference guide
   ✓ INDEX.md - Navigation and workflow guide
   ✓ DATASET_OVERVIEW.txt - This file
   
   ✓ data_loader.py - Helper functions for loading data
   ✓ visualize_data.py - Generate all visualization figures
   ✓ generate_simulation_data.py - Regenerate dataset if needed
   ✓ requirements.txt - Python package dependencies

================================================================================
KEY SPECIFICATIONS
================================================================================

DOMAIN:
  Physical size: 1.0 m × 1.0 m × 0.5 m (Length × Width × Height)
  Grid resolution: 100 × 100 × 50 cells (10 mm spacing)
  Simulation time: 1.0 second
  Time steps: 1000 (Δt = 1 ms)

STRATIFICATION:
  Interface height: z = 0.25 m (middle of domain)
  Lower layer (z < 0.25 m): Liquid phase (water)
  Upper layer (z > 0.25 m): Gas phase (air)
  Interface: Sharp with small amplitude waves (~3 cm)

FLUID PROPERTIES:
  Water: ρ=1000 kg/m³, μ=0.001 Pa·s, c=1500 m/s
  Air: ρ=1.2 kg/m³, μ=1.8×10⁻⁵ Pa·s, c=343 m/s

ACOUSTIC SOURCE:
  Frequency: 1000 Hz
  Amplitude: 1000 Pa
  Location: x=0.2 m, z=0.3 m (in liquid layer)

PARAMETER RANGES:
  Frequencies: 100 Hz to 10 kHz (50 logarithmically-spaced points)
  Void fractions: 0.0 to 1.0 (20 linearly-spaced points)
  Angles: 0° to 89° (90 points)

================================================================================
COMMON USE CASES
================================================================================

USE CASE 1: Acoustic Attenuation Study
  Files needed:
    - mathematical_model_outputs/attenuation_dB.npy
    - cfd_outputs/acoustic_pressure.npy
    - validation_data/attenuation_comparison.json
  
  Load with:
    from data_loader import StratifiedFlowData
    data = StratifiedFlowData()
    atten = data.load_attenuation(unit='dB')
    acoustic = data.load_acoustic_pressure(mmap=True)

USE CASE 2: Sound Speed Modeling
  Files needed:
    - mathematical_model_outputs/sound_speed_wood.npy
    - mathematical_model_outputs/sound_speed_dispersive.npy
    - validation_data/sound_speed_comparison.json
  
  Load with:
    sound_speed = data.load_sound_speed(model='all')
    validation = data.load_validation_data()

USE CASE 3: Flow Analysis
  Files needed:
    - cfd_outputs/velocity_u.npy, velocity_v.npy, velocity_w.npy
    - cfd_outputs/vof.npy
    - cfd_outputs/turbulence_k.npy, turbulence_epsilon.npy
  
  Load with:
    velocity = data.load_velocity_field()
    vof = data.load_vof()
    turbulence = data.load_turbulence()

USE CASE 4: Interface Dynamics
  Files needed:
    - cfd_outputs/vof.npy
    - mathematical_model_outputs/reflection_transmission.json
    - mathematical_model_outputs/reflection_vs_angle.npy
  
  Load with:
    vof = data.load_vof()
    wave_prop = data.load_wave_propagation()

FILE SIZE BREAKDOWN
================================================================================

Total dataset size: ~500 MB

Breakdown:
  CFD outputs: ~220 MB (mostly acoustic_pressure.npy at ~200 MB)
  Mathematical models: ~0.5 MB
  Validation data: ~0.5 MB

================================================================================
RESEARCH APPLICATIONS
================================================================================

This dataset enables research on:

1. Acoustic attenuation mechanisms in multiphase flows
   - Viscous attenuation
   - Scattering attenuation
   - Thermal attenuation
   - Frequency dependence

2. Sound speed characterization
   - Wood's equation accuracy
   - Frequency dispersion effects
   - Void fraction dependence

3. Wave propagation at interfaces
   - Reflection and transmission coefficients
   - Critical angle phenomena
   - Standing wave patterns

4. Flow-acoustic coupling
   - Turbulence effects on acoustics
   - Convective influences
   - Velocity shear effects

5. Model validation and development
   - Compare theoretical models with simulations
   - Test new attenuation models
   - Develop empirical correlations

6. Machine learning applications
   - Train ML models for acoustic prediction
   - Feature extraction from CFD data
   - Surrogate model development
