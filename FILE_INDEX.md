## 🛠️ TROUBLESHOOTING BY FILE

### Can't open fdi_lagos_survey_data.csv
- Make sure you're in the correct directory
- Try: `ls fdi_lagos_survey_data.csv` (Linux/Mac) or `dir fdi_lagos_survey_data.csv` (Windows)
- In Python: `pd.read_csv('fdi_lagos_survey_data.csv')`
- In R: `read.csv("fdi_lagos_survey_data.csv")`

### R script won't run (sem_analysis_code.R)
- Install packages: `install.packages(c("lavaan", "semPlot", "psych"))`
- Check R version: Should be >= 4.0
- Verify data file is in same directory

### Python scripts error
- Install dependencies: `pip install -r requirements.txt`
- Check Python version: Should be >= 3.7
- Verify data file exists

### PNG files not displaying
- File might be corrupted: Regenerate with `python3 visualize_data.py`
- Try different image viewer
- Files are high-resolution (300 DPI), may take time to load
