DATASET SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════

Input Space (Manufacturing Parameters):
  • Thermal: Peak temp, heating/cooling rates, dwell time
  • Geometry: Layer thicknesses, plate dimensions
  • Material: Ni content, YSZ dopant, porosity
  • Process: Green density, binder content

Output Space:
  • Warp Fields: 3D surface deformations (2D spatial)
  • Stress Fields: Full 3D stress tensor (3D spatial)

Spatial Resolution:
  • Warp: 50×50 grid points
  • Stress: 50×50×10 grid points
  • Customizable via command-line arguments

Data Format:
  • Warp: NumPy compressed (.npz)
  • Stress: NumPy compressed (.npz)
  • Parameters: JSON (.json)
  • Metadata: JSON (.json)
