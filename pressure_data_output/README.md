# Core Time-Series Pressure Data Dataset

## Study: Attenuation Mechanisms in Stratified Flows: Beyond Single Phase Leakage Acoustics

This dataset contains high-frequency acoustic pressure data for analyzing acoustic wave propagation and attenuation in stratified flow pipeline systems during leak events.

---

## Dataset Overview

### Purpose
To capture the detailed acoustic signature (pressure waves) generated by leaks and analyze their propagation and attenuation through stratified two-phase flow in pipeline systems.

### Key Features
- **14 High-Frequency Pressure Sensors** (PG1-PG14) strategically placed along the pipeline
- **3 Leak Locations** (A, D, E) at different positions
- **4 Test Groups** with varying configurations
- **3 Experimental Phases**: Baseline, Transient (leak event), Post-event recovery

## Data Characteristics

### Signal Components
1. **Baseline Noise**: Normal pipeline operation including:
   - Low-frequency flow turbulence (~2-5 Hz)
   - Pump harmonics (~50 Hz and multiples)
   - Electronic sensor noise

2. **Leak Acoustic Signature**:
   - Broadband turbulent noise (100-5000 Hz)
   - Orifice resonance frequencies (~800 Hz)
   - Jet instability harmonics (~1500 Hz)

3. **Attenuation Effects**:
   - Distance-dependent amplitude decay
   - Frequency-dependent absorption
   - Interface scattering (stratified flow specific)
   - Propagation time delay

## Usage Examples

### Python - Load and Analyze Data
```python
import pandas as pd
import numpy as np

# Load transient data for Group 02
df = pd.read_csv('csv_data/Group_02/Group02_transient_pressure_data.csv')

# Extract leak period (5-20 seconds)
leak_data = df[(df['time'] >= 5) & (df['time'] <= 20)]

# Calculate RMS for sensor PG3 (near leak point A)
rms = np.sqrt(np.mean(leak_data['PG3']**2))
print(f"RMS pressure during leak: {rms:.2f} kPa")
```

### Analyzing Attenuation
```python
# Compare signal amplitude at different distances from leak
leak_pos = 6.0  # meters (Leak A position)
sensor_positions = {'PG3': 5.0, 'PG4': 7.5, 'PG6': 15.0, 'PG9': 25.0}

for sensor, pos in sensor_positions.items():
    distance = abs(pos - leak_pos)
    rms = np.sqrt(np.mean(leak_data[sensor]**2))
    print(f"{sensor} at {distance}m: RMS = {rms:.2f} kPa")
```
